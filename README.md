# Student_Dashboard

An elegant and interactive **Student dashboard** built using **HTML, CSS, and JavaScript**.  
It combines essential daily tools — a **to-do list**, **notes system with tags**, **user image upload**, and a **dark/light theme toggle** — into one beautifully designed interface.

---

## Features

### To-Do List
- Add and delete daily tasks easily.  
- Mark tasks as completed using checkboxes.  
- Smooth hover effects and modern design.

### Notes System
- Create color-coded notes with title, tag, date, and content.  
- Select note colors from a cute circular color palette.  
- Tag-based filtering: click on a tag to view notes under it, and click again to show all.  
- Organized layout for readability and space balance.

### Dynamic Tags
- Automatically created from notes.  
- Each tag has its own color and can be toggled to filter notes.  
- Non-overlapping tag bar with neat spacing.

### User Image Upload
- Upload and preview a small (300x300px) profile image.  
- Option to change the uploaded image dynamically.  
- Stylish border.

### Theme Toggle
- Switch between **Light** and **Dark** modes with one click.  
- The toggle button dynamically changes icons between ☀️ and 🌙.  
- All components adapt seamlessly to theme changes.

---

## Technology Stack
**Frontend** - HTML5, CSS3, JavaScript (Vanilla JS) 
**Layout & Styling** - CSS Grid, Flexbox, Glassmorphism, Gradients, Box Shadows 
**Interactivity** - DOM Manipulation, Event Handling, FileReader API 
**User Interface** - Animated buttons, Color palette selector, Tag filters, Theme toggle

---

## How It Works
1. **To-Do Section**  
   - Enter a task and click “Add”.  
   - Mark it complete or delete it anytime.

2. **User Image**  
   - Upload a picture (300×300).  
   - Option to change image without reloading the page.

3. **Notes Panel**  
   - Add note name, tag, date, and text.  
   - Pick a note color from the color wheel.  
   - Tags appear automatically — click a tag to filter notes by category.

4. **Theme Toggle**  
   - Click the 🌙/☀️ icon on the top-right corner to switch between light and dark mode.

---

## UI Highlights
- Soft glassmorphism with blurred panels.
- Animated hover effects for all buttons.
- Cute circular color palette for note themes.
- Balanced spacing between all dashboard components.
- Non-overlapping tag bar with rounded color tags.
